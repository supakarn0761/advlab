# advlab

โปรเจกต์ตัวอย่างสำหรับรายวิชา ประกอบด้วยโปรแกรมดาวน์โหลดวิดีโอ/เสียงจาก YouTube

## ไฟล์ในโปรเจกต์

- `dlyoutube.py` — โปรแกรมดาวน์โหลดวิดีโอหรือไฟล์เสียงจาก YouTube โดยใช้ไลบรารี `yt-dlp`

## การติดตั้ง

ต้องติดตั้งไลบรารีที่จำเป็นก่อนใช้งาน:

```bash
pip install yt-dlp
```

หากต้องการดาวน์โหลดเฉพาะเสียง (audio-only) ต้องมี `ffmpeg` ติดตั้งอยู่ในเครื่องด้วย เพื่อใช้แปลงไฟล์เป็น mp3

## วิธีใช้งาน

ดาวน์โหลดวิดีโอความละเอียดดีที่สุด:

```bash
python dlyoutube.py https://www.youtube.com/watch?v=XXXXXXXXXXX
```

ดาวน์โหลดเฉพาะไฟล์เสียง (mp3):

```bash
python dlyoutube.py https://www.youtube.com/watch?v=XXXXXXXXXXX --audio-only
```

กำหนดโฟลเดอร์ปลายทางเอง:

```bash
python dlyoutube.py https://www.youtube.com/watch?v=XXXXXXXXXXX -o downloads
```

## พารามิเตอร์

| พารามิเตอร์      | คำอธิบาย                                      |
|-------------------|-----------------------------------------------|
| `url`             | ลิงก์วิดีโอ YouTube (จำเป็นต้องระบุ)          |
| `-o`, `--output`  | โฟลเดอร์ปลายทาง (ค่าเริ่มต้น: `downloads`)     |
| `--audio-only`    | ดาวน์โหลดเฉพาะเสียงและแปลงเป็น mp3            |

## ข้อควรระวัง

โปรแกรมนี้จัดทำขึ้นเพื่อการศึกษา ควรใช้ดาวน์โหลดเฉพาะวิดีโอที่เจ้าของอนุญาต หรือเนื้อหาที่ไม่ติดปัญหาลิขสิทธิ์เท่านั้น
